# specs/ — 流水线交接物

版本化的需求与任务账本。七步流水线产出落此目录（见 `.cursor/rules/execution-discipline.mdc`）。

| 目录 | 内容 |
|---|---|
| `prd/` | 需求规格 `PRD-YYYYMMDD-NN-slug.md` |
| `design/` | 大型任务可选设计短文 |
| `tickets/` | `<feature-slug>/NN-slug.md` |
| `changelog/` | 变更留痕 |

小修档也可只有对话简报 + 1 张 ticket；但实现合入前应有可追溯编号（用户明示跳过除外）。
