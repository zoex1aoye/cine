# 缓冲圈显示加载速度
- 编号：PRD-20261001-08 ｜ 确认人：用户 ｜ 档位：小修×碰播放器 ｜ 栈位：player

## 要解决什么问题（1 段）

播放中缓冲（seek/卡顿）时仅有转圈，缺少网速反馈。在转圈下方显示加载速度，并移除旧弱网文案。

## 用户故事与验收标准
作为观众，我想要缓冲时看到加载速度，以便判断是在加载还是卡住。
- [x] 缓冲持续约 0.8s 后显示「加载中 {速度|—}」（代码侧；冒烟待确认）
- [x] 缓冲结束立刻隐藏速度行
- [x] 移除「网络较弱，缓冲中…」
- [x] 不影响进页测速 ConcentricHud

## ATDD
| 场景 | 给定条件 | 操作 | 预期结果 |
|------|----------|------|----------|
| 短缓冲 | 缓冲 <0.8s | 等待结束 | 仅转圈，无速度行 |
| 长缓冲 | 缓冲 ≥0.8s 且有 cache-speed | 观察 | 「加载中 1.2 MB/s」类文案 |
| 无速度 | 缓冲 ≥0.8s 读不到速度 | 观察 | 「加载中 —」 |
| 结束 | 缓冲结束 | — | 速度行消失 |
