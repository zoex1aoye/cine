# TV / 低端 Android 硬件解码健壮性与自愈体系
- 编号：PRD-20261003-03 ｜ 确认人：用户 ｜ 档位：中型×碰播放器·跨平台 ｜ 栈位：全栈 / player

## 要解决什么问题（1 段）

在低端 Android TV / 投影仪及联发科等 SoC 设备上，MediaCodec 驱动常出现色彩对齐崩溃、OMX/C2 解码失败、或者静默假死（流已下载但第 0 秒无帧送显）。需构建全方位的解码自愈体系：扩充底层硬解异常捕获词库、增加 5 秒假死看门狗自动回退软解、受限机型启用跳帧保音画同步，并在 TV 播放控制栏提供遥控器可直达的硬解/软解切换项，消除黑屏假死盲区。

## 用户故事与验收标准

作为 TV 观众，我希望在播放各种编码视频时，即使电视硬解码器异常或驱动假死，播放器也能在数秒内自动感知并切换到可用解码模式；同时我可以使用遥控器主动切换硬解/软解。

- [ ] 扩充 `media_kit_player_native.dart` 中硬解异常日志特征捕获（覆盖 OMX/C2、dequeue output buffer、surface abandoned、amediaerror 等常见 SoC 驱动错误）。
- [ ] 增加硬解假死看门狗（Watchdog）：网络流已缓冲且处于播放态，若连续 5 秒画面进度 `position == Duration.zero` 且未完成首帧解码，判定为硬解假死并自动触发软解回退（`reopen` with `hwdec=no`）。
- [ ] 软解降载策略：在受限机型及软解回退时配置 `vd-lavc-skiploopfilter=nonkey`，在低端 4 核 CPU 上防止软解 1080P 严重掉帧与音画不同步；受限机型 `hwdec-extra-frames` 压缩为 1，保护 CMA 显存。
- [ ] 界面交互支持：在播放控制栏（及 TV 遥控器可聚焦区域）提供解码模式切换（当前硬解/软解状态展示及一键切换）。
- [ ] `flutter analyze` 无 error；单元测试与 Widget 测试全部通过。
