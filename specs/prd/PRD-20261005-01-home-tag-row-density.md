# 非电视首页 tag 行密度
- 编号：PRD-20261005-01 ｜ 确认人：用户 ｜ 档位：小修×共享组件 ｜ 栈位：ui

## 要解决什么问题（1 段）

非电视显示屏上，首页每个 tag 只摆一行。列数上限偏紧，宽屏行尾空；请求却固定 12 条，窄屏多拉、超宽又不够。电视遥控表面保持现有列数与 12 条请求。

## 用户故事与验收标准
作为非电视用户，我想要首页 tag 一行随窗口变密，并按这一行去拉片，以便宽屏能铺满、窄屏少拉多余条目。
- [x] 非电视列数上限为 3/5/6/8/12；电视仍为 3/4/5/6/8
- [x] 非电视首页 tag 行请求 `min(30, max(列数, 6))`；电视固定 12
- [x] 窗口变宽且上次请求条数不够时补拉一次；变窄不请求；片源不足不反复请求
- [x] `flutter analyze` 无 error；列数与请求条数有单测
