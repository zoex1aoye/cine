## 要解决什么问题

桌面播放区目前仅靠单击切换 `CineVideoControls` 显隐，与 README「移动鼠标唤出」不符，也无法在悬停时操作进度条。需补齐指针驱动的显隐，并调整桌面单击语义。

## 用户故事与验收标准

作为桌面用户，当鼠标进入或在播放区内移动时，我想看到进度条与操作栏，以便拖进度、点按钮；移出后立刻收起，以免挡画面。

- [ ] 桌面：鼠标进入或区内移动 → 显示控件；播放中非拖动静止约 3s → 自动隐藏
- [ ] 桌面：鼠标离开播放区（含底栏）→ 立刻隐藏
- [ ] 桌面：单击画面 → 播放/暂停（不再切换控件显隐）
- [ ] 桌面：双击左右半屏快退/快进保留
- [ ] 触控：仍点按切换控件显隐（本迭代不改单击播停）
- [ ] 内部全屏与槽内播放同一套规则（同一 `CineVideoControls`）
- [ ] macOS 冒烟：进区出控件、离区立刻藏、3s 藏、单击播停
- [ ] `flutter analyze` 无 error

## ATDD

| 场景 | 给定条件 | 操作 | 预期结果 |
|------|----------|------|----------|
| 进入显示 | 桌面、控件隐藏、正在播 | 鼠标移入播放区 | 控件显示 |
| 移动续命 | 控件已显示 | 区内移动 | 重置 3s 隐藏计时 |
| 静止隐藏 | 播放中、非 scrub | 区内静止 ≥3s | 控件隐藏 |
| 离开隐藏 | 控件显示 | 鼠标移出播放区 | 立刻隐藏 |
| 单击播停 | 桌面、正在播 | 单击画面 | 暂停；控件显隐不因单击切换 |
| 双击 seek | 桌面 | 双击右半屏 | 仍快进 |
| 触控 | 非桌面 | 点按画面 | 仍切换控件显隐 |
