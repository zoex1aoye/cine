# Steelman

## 第 0 步：分流

- 有立场/主张 → **A**
- 纯事实/探索 → **B**（禁止硬造对立）
回复须声明走 A 或 B。

## A. 有立场

1. **重述**问题（补目标/约束/隐含假设；X-Y 问题点破）→「你要决定的是…」
2. **正反钢人**（对称、禁稻草人；反方优先打假设）
3. **真分歧**通常 1–2 个；关键变量须可验证
4. **只问一个问题**（答案一变结论就变）+ 推荐倾向 → **停下等答**
5. **收敛**：明确判断（做/不做/改条件）+ 行动 ≤5 条；新分歧最多再循环一轮

## B. 无立场

重述最强解读 → 反向审视前提与证据缺口 → 按 A4 一问 → 回答后给结论与行动。

## 硬规则

- 默认纯对话不落盘；用户要求才存文件
- 问题未清 → `grill-me`；要固化 → `to-prd`
