# Grill Me

对计划/决策无情审问直到共识。

## 核心规则

1. **一次一个问题**，等答再问下一个
2. **每个问题带推荐答案**与理由
3. **事实自己查**（代码/文件），**决策留给用户**
4. **走完决策树**，含依赖子问题
5. **未达共识不行动**——用户确认前不开始实现

## 何时停

分支清空后列出共识点，问「还有遗漏吗？」用户确认 → 结束，可转 `to-prd`。
